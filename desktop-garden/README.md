# 庭院实验室 · Desktop Garden 0.4

使用 Godot 4.6.3 制作的独立 Windows 草坪塔防原型。无需安卓、模拟器、APK、OBB 或原版存档。

## 运行

解压 Windows 包，双击 `DesktopGarden.exe`。点击植物卡，再点击草坪种植；布置好后点「开始防守」或按 Enter。首次推荐打开左下角「练习模式」（初始 1000 阳光；普通模式 275）。三面旗、九波，共 72 只僵尸，守住即胜利。

准备阶段可点「切换场景」选择草坪或古埃及，切换会清空布阵并使用推荐卡组。「选择卡组」可从十三株植物中携带 1–8 张，按点击加入的顺序排列；确认卡组保留已种植物。对战开始后不能更换场景或卡组。

窗口默认 1280×720，内部画布 1600×900，保持比例缩放。每行一辆割草机，用完后再次突破则失败。

| 操作 | 按键 |
| --- | --- |
| 选择携带的植物卡 | 1–8 / 点击卡片 |
| 种植 / 收集阳光 | 左键 |
| 取消选择 | 右键 / Esc |
| 暂停 / 继续 | 空格 / P / 右上角按钮 |
| 铲除植物 | X，再点击植物 |
| 使用能量豆 | F，再点击植物；每局三颗 |
| 声音开关 | M / 右上角声音按钮 |
| 全屏 / 窗口 | F11 |

准备阶段不推进波次、不产阳光。普通阳光 25，大阳光 40；12 秒不收集会消失。运行中的对局需连续点击两次「重开」，胜负界面可直接再玩。

## 本版进展

- 原版前院和埃及背景，十三株植物的首批原版 PAM 动作；共 32 个角色/变体/特效、143 段动作。
- 埃及每行一个 700 血墓碑：阻挡种植和普通直线弹丸；卷心菜抛射越过墓碑，回旋镖可穿过并伤害墓碑，噬碑藤可吞噬墓碑。僵尸可穿过墓碑，胜利不要求清空墓碑。
- 准备阶段支持选卡组与切换场景。埃及当前沿用九波防守规则，还不是完整埃及战役。
- 普通、路障、铁桶、巨人的行走/啃咬/倒地动作；路障、铁桶有两级受损外观，护甲耗尽后显示普通身体。
- 倭瓜现在有蓄力、起跳、移动、下落和落地判伤；空中不可被啃咬，普通两次各 600 后离场。
- 原音效的部分变体已接入：射击、命中、阳光、种植、铲除、倭瓜与能量豆。音效有节流和八声部限制，M 可静音。Wwise 的完整切换、混音与全部音效仍未实现。
- 固定 60 Hz 战斗步长、扫描碰撞、单次穿透命中去重、状态计时、割草机、暂停、重开、胜负和本地胜场。

| 植物 | 普通行为 | 能量豆行为 |
| --- | --- | --- |

火焰对冰减速目标的本次伤害再乘 1.25，随后清除冰减速和冻结，不清除甜豌豆的非冰减速。甜豌豆扩大的是减速范围，未顺带扩大溅射伤害范围。

## 当前范围

仍是独立原型，不是完整 PVZ2 一比一复刻。目前只有上述十三株植物及两种场景，尚未实现全部植物、全部僵尸技能、世界机制、恐龙、完整升级、原版关卡导入、音乐和原版存档。巨人的砸击/扔小鬼、全部断肢与护甲碎片等也待补齐。冰豆的普通冻结 1 秒是原型当前规则，不能作为原版全部等级行为。

本版使用原 PAM 时间轴、嵌套变换、原贴图与颜色；发射事件读取动画标记。原版 rig 的运行时控制在本引擎内逐项实现，例如隐藏服装/黄油/墨汁辅助层、选择护甲外观、倭瓜位移和落地判定。尚未保证每一项动画控制、粒子、音效分支和交互细节与原版一致。

`Garden.gd` 为主战斗与 UI，`Expansion.gd` 为埃及墓碑及新增植物，`OriginalAnimations.gd` 为动画绘制，`DATA` 为当前植物数值。音频、背景和动画来源记录在 assets 下的清单及转换工具中。

## 验证

- 30 项战斗检查：费用、占格、冷却、扫描碰撞、3×3 减速范围、穿透、火树冰火增伤、寿命、砸击、啃咬、割草机、胜负和重开。
- 16 项交互/整局检查：选卡、种植、取消、开始、暂停、收阳光、能量豆、铲子、声音开关，以及九波 72 只僵尸的完整模拟。
- 38 项动画检查：32 种角色/护甲变体/特效、帧结构、有限矩阵、原发射事件、锚点与回退。
- 25 项大招/表现检查：60/30 发计数、六个 40 阳光、护甲吸收与溢出、蓝火增伤、倭瓜跨行跳跃并返回、音效及背景资源加载。
- 40 项新增机制检查：墓碑阻挡与吞噬、抛射绕过墓碑、回旋镖往返计数、土豆雷准备/爆炸/复制、菜问背后目标与范围大招、全场抛射、场景和卡组交互。
- 在 Linux Godot 下实际渲染准备、战斗、大招、埃及及选卡画面。Windows x86-64 Release EXE 已导出，并在 Linux 引擎加载其内嵌资源验证；未声称在 Windows 本机运行通过。
- 无界面模拟不提交音频播放，音效文件经过转码、解码及资源加载检查；当前环境没有实际扬声器验听。

## 源码运行与测试

用 Godot 4.6.3 导入 `project.godot`，按 F5 运行。导出 Windows 需安装同版本导出模板。使用 Compatibility / OpenGL 渲染。

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/combat_test.gd
godot --headless --path . --script res://tests/ui_flow_test.gd
godot --headless --path . --script res://tests/animation_test.gd
godot --headless --path . --script res://tests/power_test.gd
godot --headless --path . --script res://tests/expansion_test.gd
```

Windows 配置在 `%APPDATA%/Godot/app_userdata/庭院实验室 · Desktop Garden/desktop_profile.cfg`，保存胜场与声音开关，和原版 `pp.dat` 独立。0.1–0.3 的胜场可以沿用。

## 资源转换

23 卷 RAR 通过完整校验，StructInfo 的 2,982 个分包均存在。只读取实际 .rsgp，不混用 Packages 解包缓存。仅把当前用到的素材加入 EXE，没有打包整份 OBB。

```sh
python -m pip install -r tools/requirements.txt
python tools/import_original_animations.py /path/to/obb.dir assets/animations
python tools/extract_lawn.py /path/to/obb.dir assets
python tools/extract_egypt.py /path/to/obb.dir assets
```

音效转换另需 FFmpeg/ffprobe，以及外部 ww2ogg 程序与其 aoTuV 603 codebook：

```sh
python tools/extract_effect_audio.py /path/to/obb.dir assets/audio /path/to/ww2ogg /path/to/packed_codebooks_aoTuV_603.bin
```

只玩游戏不需要这些转换工具。导入器支持当前批次 PAM v6 与 PTX RGBA8888 / ETC1+A8，不是全部原版资源格式的完整通用实现。转换清单记录了来源分包、动作和音频媒体编号。

Godot 与字体许可证随包提供；用户提供的游戏素材不属于 Godot 或字体许可证范围。
