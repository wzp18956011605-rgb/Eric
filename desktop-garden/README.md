# 庭院实验室 · Desktop Garden 0.2

独立 Windows 草坪塔防原型，使用 Godot 4.6.3。无需安卓、雷电模拟器、APK、OBB 或原版存档。

## 开始游戏

解压 Windows 包，双击 `DesktopGarden.exe`。准备阶段点击植物卡再点击草坪，布置好后点击「开始防守」或按 Enter。推荐首次开启左下角「练习模式」：初始 1000 阳光；普通模式初始 275。守住三面旗、九波共 72 只僵尸即获胜。

窗口默认 1280×720，内部画布 1600×900，窗口缩放保持比例；F11 切换全屏。无需安装 Godot 编辑器即可运行 EXE。

| 操作 | 按键 |
| --- | --- |
| 选择八张植物卡 | 1–8，或鼠标点击 |
| 种植 / 收集阳光 | 鼠标左键 |
| 取消当前选择 | 鼠标右键 / Esc |
| 暂停 / 继续 | 空格 / P / 右上角按钮 |
| 铲子 | X，再点击植物 |
| 能量豆 | F，再点击植物；每局三颗 |
| 全屏 / 窗口 | F11 |

准备阶段允许种植，但不生产阳光、不推进波次；开始后阳光持续 12 秒，点击收集 +25。每行有一辆割草机，用完后再次被突破则失败。重开运行中的对局需要连续点击两次「重开」，胜负界面可直接再玩。

## 已实现

- 五行九列草坪；阳光、植物费用与独立卡槽冷却；普通/练习模式。
- 向日葵、豌豆、坚果、寒冰射手、甜豌豆、机枪喷、火炬、倭瓜。
- 甜豌豆直击 40、周围溅射 10、命中格周围 3×3 的僵尸非冰系减速 50% 持续 2 秒；大招立即发射 1800 伤害穿透糖弹，每个目标只命中一次。
- 机枪喷每 1.425 秒发起四发连射，发射时机读取原动画事件、三格射程、存活 30 秒。素材来自你提供的机枪喷样本，已接入原 PAM 待机和攻击动作。
- 普通豌豆经火炬伤害翻倍；火焰对冰减速目标额外增伤 25%，随后移除冰减速/冻结，不消除非冰减速。
- 冰豌 50% 发出冻结弹；当前原型冻结 1 秒，普通冰弹减速 10 秒，具体持续时间仍需对照原版。
- 倭瓜两次各 600 的近距离砸击；坚果 4000 血。
- 普通、路障、铁桶、巨人；巨人 3600 血；碰撞、啃咬、生命条、伤害反馈与割草机。
- 60 Hz 固定步长战斗、扫描式子弹碰撞、跨帧一致的状态计时；胜负、暂停、重开和本地胜场记录。

## 当前范围

这是可玩的第二版，不是完整 PVZ2 一比一复刻。首批八株植物已接入原 PAM 中选定的待机/攻击/受损动作；普通、路障、铁桶和巨人也使用原版身体、护甲与行走/啃咬/倒地动作。原服装、黄油、墨汁和测试辅助层在正常状态下隐藏。声音、其余植物、世界机制、恐龙、全部等级、原版关卡格式和原版存档尚未接入。各植物的大招也只是原型实现：射手类用一发穿透弹、向日葵出六个阳光、其余回血，不能当作原版全部大招。动画来自此次上传的 23 卷 RAR 解包资源，使用按帧展开的嵌套变换、原始贴图和颜色；不是用几张截图猜动作。当前只接入选定动作，尚未覆盖完整植物大招、倭瓜完整腾空落地、断肢和全部僵尸状态。动画绘制在 `OriginalAnimations.gd`，战斗逻辑在 `Garden.gd`。

各植物数值集中在 `Garden.gd` 的 `DATA`，波次在 `make_wave()`；后续可以独立拆成数据文件与场景。在已有原型上逐项接入，而不是继续给安卓 lib 打补丁。

## 验证情况

- Godot Linux 引擎实际加载、运行，并在 X11/OpenGL 软件渲染下输出准备与战斗截图。
- 30 项战斗检查：费用、占格、冷却、跨帧碰撞、跨行隔离、溅射、穿透去重、火树增伤/解冻、冰冻、机枪喷寿命与四连发、倭瓜两击、啃咬、割草机、胜负与重开。
- 14 项交互及整局检查：选卡、种植、取消、开始、暂停、阳光、能量豆、铲子，以及九波 72 只僵尸的完整模拟。
- 18 项动画检查：12 种角色/护甲变体、帧结构、有限矩阵、四次发射事件、护甲锚点、事件时序及回退。
- Windows x86-64 Release EXE 已导出；当前环境没有实际 Windows 系统，未声称完成 Windows 本机验证。

## 源码运行和测试

用 Godot 4.6.3 导入 `project.godot`，按 F6/F5 运行；导出 Windows 需在编辑器安装同版本导出模板。项目使用 Compatibility / OpenGL 渲染。

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/combat_test.gd
godot --headless --path . --script res://tests/ui_flow_test.gd
godot --headless --path . --script res://tests/animation_test.gd
```

Windows 设置文件位于 `%APPDATA%/Godot/app_userdata/庭院实验室 · Desktop Garden/desktop_profile.cfg`，仅保存胜场，和原版 `pp.dat` 完全独立。

Godot 与字体的许可证见随附文件；用户提供的游戏图片不属于 Godot 或字体许可证范围。

## 原资源导入

原 RAR 的 23 个分卷通过 unrar 整包校验。StructInfo 记录的 2,982 个分包全部存在；包含 1,290 个 PAM、2,029 个 PTX 条目、351 个 BNK、649 个 WEM 条目（条目统计包含分辨率及组合，不等于独立角色数）。原包里有 Packages 解包缓存，导入器只读取实际 .rsgp，不混用缓存。

复现首批动画转换：

```sh
python -m pip install -r tools/requirements.txt
python tools/import_original_animations.py /path/to/obb.dir assets/animations
```

`assets/animations/conversion-report.json` 记录角色、来源与实际接入动作。这里只导入首批动作，未把整份 OBB 打进 EXE。导入器目前支持该批 PAM v6、PTX RGBA8888 / ETC1+A8，正常状态服装/护甲层经过显式筛选；不是对全部原版资源格式的通用完整实现。
